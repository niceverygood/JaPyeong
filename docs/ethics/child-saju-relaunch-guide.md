# 자녀 사주 — 9개월 후 재출시 가드 가이드

> **현재 정책**: 자녀 사주 단독 상품 **6개월 출시 보류 (윤리 검증)**
> **이 문서**: 9개월 시점 (2027-03) 재출시 검토할 때, 반드시 확인할
> 윤리·법무·운영 체크리스트. **하나라도 못 채우면 재출시 하지 않는다.**

작성: 2026-06-07
다음 검토 시점: 2027-03-07
책임자: CEO + 법무

---

## 1. 왜 6개월 보류했는가 (배경)

| 위험 | 구체 시나리오 |
|---|---|
| 부모가 자녀 진로·결혼·전공을 사주로 결정 | 자녀의 자기결정권 침해 — 정신건강 영향, 가족 갈등 |
| 14세 미만 개인정보 수집 | 개인정보보호법 제22조의2 — 법정대리인 동의 + 최소 수집 의무 |
| "이 아이는 위험한 사주" 라벨 | 낙인 효과 — 평생 트라우마 |
| 자녀 본인 모르게 분석 | 본인 동의 미비 — 14세+ 시 본인 동의 의무 |
| 입시·취업에서 자녀 사주 활용 | 차별 우려 — ISMS-P 영향평가 필수 |

→ **이 5개 위험을 모두 통제할 수 있을 때만** 재출시.

## 2. 재출시 사전 체크리스트 (모두 ✅ 시에만 진행)

### 🟦 법무·컴플라이언스 (필수)
- [ ] 개인정보보호위원회 사전 의견서 수령 (14세 미만 자녀 사주 분석에 대한 적법성)
- [ ] ISMS-P 인증 또는 그에 준하는 영향평가 완료
- [ ] 법무 자문 (외부 로펌) 의견서 — 약관·동의서 검토 완료
- [ ] 정신건강의학과 전문의 1명 이상 자문 — "낙인 위험" 평가

### 🟪 제품 가드 (필수)
- [ ] **자녀 본인 동의 게이트** — 14세+ 자녀에게 카톡·문자로 동의 링크 발송,
      본인 클릭 후 분석 시작
- [ ] **부정적 표현 사전** 차단 — "위험·문제·결함·잘못된" 등 자녀 분석에서
      자동 차단 (현재 단정어 금지어 사전에 추가)
- [ ] **AI 응답 추가 가드** — 자녀 사주 분석 시 시스템 프롬프트에 다음 명시:
      "자녀의 자기결정권을 존중하고, 부모가 결정을 강요하지 않도록 표현"
- [ ] **결정 강요 차단** — "이렇게 하세요·따르세요" 어휘 사용 금지 (자녀 분석 응답)
- [ ] **위기 키워드** — 자녀 분석 중 자살·자해·우울 키워드 감지 시 즉시 1577-0199
      (청소년상담복지센터) 안내

### 🟥 운영·UX 가드 (필수)
- [ ] 결제 페이지에 **윤리 안내 모달** 강제 (5초 카운트다운, 동의 체크 필수)
- [ ] **자녀 입력 시 최소 수집** — 생년월일 + 출생 시간만, 이름 옵션
- [ ] **분석 결과 부모 단독 열람 불가** — 14세+ 시 자녀 본인에게도 동일 사본 제공
- [ ] **부모-자녀 합 분석은 자녀가 동의 시에만** — 부모 단독 결제 시 거부
- [ ] **삭제 요청** 24시간 내 처리 (PII 암호화 + 즉시 삭제)

### 🟩 검증·모니터링 (필수)
- [ ] 베타 사용자 50명 + 자녀 50명 — 윤리 가드 작동 검증 (3개월 모니터링)
- [ ] 외부 자문위원 (정신건강의학과 + 법무 + 청소년 상담사) 분기 1회 리뷰
- [ ] 자녀 사주 관련 CS 클레임 0건 유지 (6개월)
- [ ] **즉시 중단 트리거** — 클레임 발생 시 24시간 내 서비스 중단 + 환불

## 4. 만약 채우면 (재출시 시 출시 형태)

### 🌱 점진적 출시
1. **Phase A (1개월)**: 자녀 14세+ 본인 동의 베타 50팀
2. **Phase B (3개월)**: 입증된 가드 + CS 데이터 → 일반 출시
3. **Phase C (6개월)**: 만족도·클레임 모니터 → Family 패키지 통합

### 💰 가격 (별도 BM 검토)
- 자녀 사주 단독: 월 49,000원 (부모 결제, 자녀 본인 동의 필수)
- Family 패키지 흡수: 만 5인 590,000원 내 자녀 포함

### 🚫 절대 금지 (재출시해도 영구 X)
- 입시·취업 결과 예측
- 자녀 결혼 상대 사주 매칭
- "이 자녀는 ~한 사람" 식 단정형 라벨링
- 학원·과외 추천 등 사교육 연계
- 부모만 결과 열람 (14세+ 시)

## 5. 비상 대응 — 이미 출시했는데 사고 났을 때

1. **즉시 (1시간 이내)**
   - 자녀 사주 모든 엔드포인트 503 응답 전환
   - 해당 시점 모든 자녀 분석 데이터 격리 (별도 테이블 이관)
   - CEO·CTO·법무 비상 통화

2. **24시간 이내**
   - 영향 받은 사용자 전수 통보 (이메일 + 카톡)
   - 자녀 데이터 완전 삭제 옵션 제공 (1클릭)
   - 환불 자동화 시작 (전액)

3. **7일 이내**
   - 사고 보고서 공개 — 원인 + 재발 방지 대책
   - 외부 감사 의뢰 (정보보호위원회 신고 포함)
   - 자녀 사주 기능 무기한 중단
