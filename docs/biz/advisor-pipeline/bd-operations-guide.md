# 자문위원 영입 BD 운영 가이드 — v1

> **대상**: 자평 BD 풀타임 1인 (Sprint 1-2 채용 권장)
> **목표**: 6개월 내 자문위원 풀 **5명 시그너처 + 20명 액티브**
> **예산**: 6개월 4,000만 원 (BD 월 500만 × 6 + 사인 보너스 5명 × 100만 + 운영비 500만)

---

## 0. 한 페이지 요약

```
[리드 수집]   리스트업 100명 → 컨택 70명 (응답률 30%)
   ↓
[1차 미팅]   응답 21명 → 미팅 14명 (미팅 전환 67%)
   ↓
[협상]       미팅 14명 → 협상 7명 (긍정 응답 50%)
   ↓
[계약]       협상 7명 → 시범 5명 → 본 계약 4명
   ↓
[온보딩]     본 계약 4명 + 추천 1명 = 6개월 5명 시그너처

목표 KPI: 월 1명 계약 / 50명 컨택 / 만족도 평균 9/10
```

## 1. 자문위원 리드 수집

### 1.1 1차 리스트업 채널 (BD 첫 2주 핵심 작업)

| 채널 | 추정 풀 | 우선순위 |
|---|---|---|
| 한국역술인협회 등록 회원 | ~500명 | ★★★★★ |
| 명리학 관련 박사·석사 학위자 (KCI 검색) | ~100명 | ★★★★ |
| 정통 명리 출판 저자 (교보·yes24 검색) | ~80명 | ★★★★★ |
| 명리 채널 유튜버 (구독자 1만+) | ~30명 | ★★★★ |
| 명리·동양철학 대학 강사 | ~50명 | ★★★ |
| 자평 사용자 중 "본인이 명리학자" 자기소개 | (사용자 늘면) | ★★★ |
| 명리 카페·커뮤니티 운영자 (네이버 등) | ~50명 | ★★★ |

→ 6개월 목표: **마스터 리스트 200명 수집**, 그중 100명에게 컨택.

### 1.2 후보 검증 체크리스트

각 후보에 대해 BD가 컨택 전 확인:
- [ ] 명리학 관련 정식 경력 (저서·논문·매체·강의 중 최소 1개)
- [ ] 디지털 자취 (홈페이지·SNS·유튜브 — 본인 확인용)
- [ ] 자평 정체성과 양립 가능한 톤 (단정형·자극 마케팅 안 하는지)
- [ ] 6개월 내 자평이 받은 적 있는 컨택인지 (CRM 확인)
- [ ] 연락처 출처 명시 가능한지 (개인정보보호법)

### 1.3 등급 분류

| 등급 | 기준 | 단가 | 협상 우선순위 |
|---|---|---|---|
| **1급 (Tier 1)** | 저서 5권+ / 매체 정기 출연 / 박사 학위 | 회당 10~15만 | 첫 사인 5명 |
| **중급 (Tier 2)** | 저서 1~4권 / 명리원 운영 5년+ / 인플루언서 | 회당 5~8만 | 본 운영 확대 |
| **신규 (Tier 3)** | 명리학 전공 박사/석사 / 채널 운영 2년+ | 회당 3~5만 | 12개월차 이후 |

## 2. 영입 파이프라인 — 5단계

### Stage 1 · Lead (수집)
- **상태**: 후보 정보만 있음, 컨택 전
- **다음 액션**: 메일 템플릿 1번 발송
- **이동 조건**: 메일 발송 완료
- **체류 기간**: 평균 0~3일

### Stage 2 · Contacted (1차 컨택)
- **상태**: Cold/Warm 메일 발송 완료
- **다음 액션**:
  - D+7 무응답 → follow-up 메일 (템플릿 2번)
  - D+14 무응답 → 더 이상 컨택 X (상태 → Declined)
  - 응답 → Stage 3 (Met)
- **체류 기간**: 평균 7~14일

### Stage 3 · Met (1차 미팅 완료)
- **상태**: 화상 미팅 진행 후
- **다음 액션**:
  - 긍정 응답 → 계약서 초안 + 소개서 송부 (템플릿 4번)
  - 보류 → D+14 후 follow-up
  - 거절 → 추천 부탁 (템플릿 5번)
- **체류 기간**: 평균 1~3주

### Stage 4 · Negotiating (협상)
- **상태**: 계약서 검토 중
- **다음 액션**:
  - 단가·독점·지분 협상 (회의 1~2회)
  - 자문위원 본인 법무 검토 진행 시 자평 일부 비용 부담
- **체류 기간**: 평균 2~6주

### Stage 5 · Signed (계약 완료)
- **상태**: 양사 서명
- **다음 액션**:
  - 시범 운영 3개월 시작
  - 자평 어드민 계정 발급 + 4시간 온보딩 교육
  - 첫 매칭 D+7 내
- **체류 기간**: 3개월 → 본 계약 전환

### 종료 상태
- **Declined**: 거절 (3개월 후 재컨택 가능)
- **Paused**: 시점 안 맞음 (6개월 후 재컨택)
- **Lost**: 영구 거절 또는 부적격 (재컨택 X)

## 5. 자문위원별 표준 운영 플로우 (계약 후)

### 5.1 온보딩 (Day 1~7)
- [ ] 자평 어드민 계정 발급
- [ ] 자문위원 프로필 작성·게재 (사이트·앱)
- [ ] 4시간 교육: 자평 정체성 / 카피 가이드라인 / 매칭 시스템 / 녹취·CS
- [ ] 첫 시범 상담 1건 (자평 운영팀 동석, 피드백)
- [ ] PI 보험 가입 완료

### 5.2 정상 운영 (Week 2~)
- 자문위원: 주간 가용 시간 등록 (캘린더 동기화)
- 자평: 사용자 매칭 → 자문위원에게 알림
- 자문위원: 상담 진행 → 녹취 + 메모 → 자평 어드민에 업로드
- 자평: 정산 (매월 말일 마감 / 익월 15일 지급)

### 5.3 분기 평가
- 자문위원 만족도 (자평 운영팀 → 자문위원)
- 사용자 만족도 (자문위원별 NPS)
- 단가·조건 재협의 (필요 시)

## 6. 위기 대응 매뉴얼

### 6.1 자문위원이 가드레일 위반 시
1. **1회 위반** (예: "이 사주는 분명히 부자가 된다" 단정 표현)
   - BD가 24시간 내 자문위원에게 통보 (이메일 + 통화)
   - 카피 가이드라인 재숙지 요청
   - 다음 상담 전 자평 운영팀 피드백 미팅
2. **2회 위반** — 자문 일시 정지 (최대 2주)
3. **3회 위반** — 계약 즉시 해지 (제13조)

### 6.2 자문위원이 사용자와 직접 거래 시도 시 (이탈 유인)
- 즉시 자평 BD 통보
- 자문위원에게 위약금 청구 통보 (제5조)
- 외부 변호사 자문 후 후속 조치

### 6.3 자문위원이 사용자 정보 유출 시
- 즉시 계약 해지 + 위약금 청구
- 자평이 사용자에게 즉시 통보 + 개인정보위 신고

### 6.4 자문위원이 자평을 비방하거나 경쟁사로 이직 시
- 독점 위반 위약금 청구 (3년 잔여 기간 자문료 50%, 최대 1억)
- 자평 PR 대응 (반박 자료 사전 준비)
