# 자평 해자(Moat) 전략 — 3축

> **출처**: 경쟁사 적대적 검증 결과
> **핵심 발견**: 기술(결정론 엔진·학파·고전)은 **6개월 내 모두 모방 가능**.
> 진짜 해자는 **관계·계약·데이터**에 있다.

---

## 0. 약한 해자(weak moat)의 실체

| 자평이 자랑하던 차별점 | 모방 난이도 | 평가 |
|---|---|---|
| 결정론 명리 엔진 | 6개월 (`sxtwl` 등 오픈소스 평준화) | ❌ 해자 아님 |
| 학파별 견해 표기 (자평·궁통·맹파) | 3개월 (프롬프트 + RAG) | ❌ 해자 아님 |
| 고전 인용 (연해자평·삼명통회) | 1개월 (Claude/GPT에 한 줄 추가) | ❌ 해자 아님 |
| 한자 자동 병기 + hover | 2주 | ❌ 해자 아님 |
| AI 보조 통변 | 즉시 (모든 경쟁사) | ❌ 해자 아님 |

→ 기술 우위는 곧 commodity가 됩니다. **시간이 흐를수록** 자평의 차별점은 약해집니다.

## 1. 진짜 해자 — 3축

### 1.1 ❶ 결정 추적 데이터셋 (Decision Outcome Dataset)

**무엇인가**
- 사용자가 입력한 결정 (이직·결혼·이주·창업) + 6개월 후 만족도 follow-up
- 자평이 제공한 명리 자문 vs 실제 결정 결과 매핑
- 시간이 갈수록 누적되는 데이터셋

**왜 해자인가**
- 경쟁사가 카피 불가 — **시간이 필요**
- 1만 건 누적 시: "이 격국·일주의 사람이 이런 결정에서 이렇게 만족" 같은 통계적 패턴 도출 가능
- 자문 품질의 **객관적 근거**가 됨 (자평만 가짐)

**6개월 마일스톤**
- Sprint 11-12: 데이터 자산화 v1, 1만 건 익명 데이터셋
- 9~12개월차: 패턴 도출 + 자문 품질 가이드라인
- 18개월차: "자평 결정 인덱스" 공개 (PR 자산)

**보호**
- 사용자 동의 (가입 시 익명 통계 활용 동의)
- 개인정보 비식별화
- 데이터셋 자체는 비공개 (분석 결과만 공개)

### 1.2 ❷ 자문위원 3년 독점 계약 (Advisor Lock-in)

**무엇인가**
- 한국 1급 명리학자 50명 내외 = **희소 자원**
- 자평이 5명 → 20명 → 50명 풀 확보 + 3년 독점 + 위약금 + 지분/스톡옵션

**왜 해자인가**
- 자문위원 자체가 유한 자원
- 한 번 자평과 계약하면 3년 동안 경쟁사로 못 감
- 자문위원 본인 브랜드를 자평 채널이 키워주면 **sticky** (떠나기 어려움)

**6개월 마일스톤**
- Sprint 5-6: 자문위원 5명 영입 + 3년 독점 계약
- Sprint 9-10: 자문위원 15명 풀
- 12개월차: 50명 풀 (희소 자원 점유)

**계약 조건 (필수)**
- 3년 독점 (경쟁 플랫폼 활동 금지)
- 위약금 조항 (계약 해지 시)
- 지분/스톡옵션 (단순 자문료 X, 공동 자산화)
- 본인 채널·노출 보장 (자평 PR이 자문위원 개인 브랜드도 키움)
- PI(전문가배상책임) 보험 가입 권장

**Fallback** (1급 영입 어려울 시)
- 2급 200명 풀 자평 플랫폼에서 **육성** → 공급 분산
- 자평이 명리 자격증 인증 기관과 파트너십

### 1.3 ❸ B2B / 엔터프라이즈 라인업

**무엇인가**
- 대기업 임원 코칭 (CEO·임원 사주)
- 채용 적성 컨설팅 (인사팀)
- 팀 조합 자문 (부서장 + 팀원 사주 호환)
- 결혼정보회사 매칭 사주
- 부동산·법무·금융권 의사결정 자문

**왜 해자인가**
- 빅테크(카카오·네이버)가 **안 옴** — 카테고리 충돌·민감도 이유
- C2C 앱이 **못 들어옴** — 영업·신뢰·SLA 필요
- 건당 100~500만 원 단가, 자평 매출 다변화
- B2C 브랜드 격상 효과 (B2B 레퍼런스 = 신뢰 증명)

**6개월 마일스톤**
- Sprint 9-10: 베타 3사 시범
- Sprint 11-12: 1건 정식 계약
- 12개월차: B2B 매출 비중 10% (전사 매출 다변화)

**진입 영역 우선순위**
1. 결혼정보회사 매칭 (감정노동 적은 인접 도메인)
2. HR 컨설팅사 채용 보조 (B2B2C 형태)
3. 대기업 임원 1:1 (영업 lead time 길지만 단가 높음)
4. 부동산 택일 컨설팅 (B2B 일회성)

| ❌ 카카오·네이버처럼 빅테크 모방 | 무모. 빅테크가 진입하면 3개월 못 버팀 |

## 3. 자평의 톤(의사결정 자문) — 시장 크기 한계 인정

### 한국 사주 시장 80% = "재미·위로·기복"
- 오늘의 운세, 궁합, 결혼운, 부적
- 자평의 "의사결정 자문" 톤과 다름

### 자평이 노릴 시장 = 상위 20% 프리미엄
- "결정 앞에 짚어볼 만한 도구" 로 포지셔닝
- TAM 자체는 작음 (예: 100억 시장 × 30% 점유 = 30억)
- 그래서 **객단가 높게 + B2B + 자문위원 1:1** 구조로 매출 보강

### Wedge 전략
- 의사결정 톤으로 **상위 20% 진입 → 락인**
- 락인 후 "기복·위로" 라인업 추가 가능 (단 브랜드 희석 주의)
- 별도 브랜드 운영도 옵션 (예: "자평 → 자평Lite"
)

## 4. 빅테크 진입 대응

### 카카오/네이버가 풀스윙으로 사주 진입하면?

**시나리오**: 카카오톡 + 카카오페이 + CLOVA-X = AI 사주 무료 출시

**자평의 응답 — 3개월 내 피벗**
1. **즉시 가격 인상** — 빅테크는 박리다매. 자평은 **고가 1:1 영역**에서 격차 벌리기
2. **B2B 비중 50%+** — C2C 매출 의존도 낮추기
3. **자문위원 풀 50명** 빠르게 확보 (빅테크는 사람 영입 못 함)
4. **오프라인 컨설팅** 라인업 (AI는 못 함)
5. **결정 추적 데이터** 차별점 부각

**카카오·네이버가 안 올 영역에 정착**
- 건당 100만 원 + 임원 1:1
- 결혼정보회사 매칭
- 자문위원 오프라인 컨설팅

## 5. 자문위원 풀 빼앗기 대응

### 경쟁사가 자문위원 2배 보수로 빼가면?

**방어책**
1. **지분/스톡옵션** 제공 — 단순 자문료가 아니라 공동창업자급
2. **3년 이상 독점 계약 + 위약금** — 법적 lock-in
3. **자문위원 본인 브랜딩 강화** — 자평 채널이 본인 유튜브보다 큰 노출 제공 → sticky
4. **1급 50명 의존 X** — 2급 200명 풀을 자평 플랫폼에서 **육성**해서 공급 분산

## 6. AI 가격 1/10 시나리오 (2~3년 내)

**예상**: Claude/GPT haiku급 모델 가격 90% 인하 → AI 응답 자체 무료 수렴

**자평의 차별점 재설정**
- AI 응답 품질 ❌ (commodity)
- **데이터셋 (결정 추적 로그)** ✅
- **자문위원 네트워크 (3년 독점)** ✅
- **브랜드 신뢰 ("자평이 말하면 믿을 만하다")** ✅
- **오프라인/하이브리드 서비스 (AI는 못 함)** ✅

**Fallback 인프라**
- 멀티 LLM (Claude + GPT + Gemini + 오픈소스 fallback)
- 캐싱 강화
- 자체 fine-tuned 소형 모델 백업

## 7. 자평이 6개월 내 망할 시나리오 5가지 + 방어법

| # | 시나리오 | 방어법 |
|---|---|---|
| 1 | **포스텔러가 "AI 자문" 모드 출시** → 자평 차별점 소멸 | 자문위원 3년 독점 + B2B 채널 선점 |
| 2 | **AI 응답 사고** (틀린 사주 결과 → 환불·민원 폭주 박제) | 결정론 엔진 자동 검증 + 자문위원 사후 검수 SLA |
| 3 | **TM 파트너십 무산** → 매출 0 | D2C(앱·인스타광고) 백업, 채널 의존도 50% 이하 |
| 4 | **카카오 운세 리뉴얼 + CLOVA-X 결합 출시** | 고가·전문가·오프라인 영역으로 즉시 피벗 |
| 5 | **AI 비용 폭증** (Claude/GPT 가격 인상 or API 차단) | 멀티 LLM + 캐싱 + 자체 모델 백업 |

**추가 PR 리스크**: 종교계·소비자단체 "미신 상술" 공격
**방어**: "엔터테인먼트·자기성찰 도구" 면책 문구 + 의료·법률 자문 대체 아님 명시
