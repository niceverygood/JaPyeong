# 자평(子平) × TM 파트너십 제안서

> **수신**: 텔레마케팅 조직 대표
> **발신**: 자평 운영팀
> **목적**: 자평 연간 패키지(40만 ~ 180만 원/년)의 텔레마케팅 판매 위탁
> **요청 결정**: 1개월 파일럿(상담사 5명 규모) 진행 합의

## 1. 시장 기회 — 왜 지금, 왜 사주인가

### 1.1 한국 사주·명리 시장의 크기
- 국내 사주·역학 시장 규모: 추산 **연 4조 원** (2023, 한국역술인협회 등)
- 그중 디지털 비중 5% 미만 — 대부분 오프라인(명리원, 점집, 부적 등)
- 1회 명리원 상담가: **7만 ~ 20만 원**, 평균 **10~15만 원**
- 핵심 소비자: **40~60대 여성** (가족·자녀·결혼·이주 의사결정의 게이트키퍼)

→ **TM 채널과 정확히 일치하는 인구·매체 행동·결제 패턴.**

### 1.2 기존 사주 앱이 못 채우는 공백
| 기존 사주 앱 | 한계 |
|---|---|
| 점·타로 챗봇 | 정통성 없음, 결정에 못 씀, 단가 안 나옴 |
| 만세력 도구 | 풀이가 없음, 무료/저가 |
| 1인 명리원 사이트 | 본인 직접 풀어줘서 확장 불가 |
| **자평** | **결정론 명리 엔진 + AI + 자문위원**의 3층 구조로 정통성 + 확장성 모두 충족 |

### 1.3 평생 가치(LTV) 잠재
- 사주는 **결정 시점마다 다시 본다** (이직·결혼·자녀·이사 등) → **갱신율 자연 발생**
- 한 명 고객이 **본인 + 배우자 + 자녀 + 부모** 사주를 들고 옴 → 가족 패키지(VIP) 업셀
- 평생 5~10년 단위 단골이 흔함 (오프라인 명리원 단골 패턴 그대로)

## 2. 자평이란 — 5분 안에

### 2.1 3층 구조 (다른 사주 앱과 결정적으로 다른 점)

```
┌─────────────────────────────────────────────────────┐
│  Layer 1 · 룰베이스 명리 엔진 (결정론적)             │
│    절기·진태양시·60갑자·격국·용신·대운 자동 산출      │
│    → AI가 사주를 푸는 게 아님. 사주는 코드가 확정.     │
├─────────────────────────────────────────────────────┤
│  Layer 2 · AI 자문 (Claude 기반)                     │
│    엔진 결과 위에서 해석만. 학파별 견해 솔직히 표기.   │
│    연해자평·삼명통회 등 고전 출처 의무 인용.           │
├─────────────────────────────────────────────────────┤
│  Layer 3 · 명리 자문위원 (사람)                       │
│    프리미엄/VIP 패키지에서 1:1 검증·상담.             │
│    "AI가 못 보는 부분"을 사람이 마무리.                │
└─────────────────────────────────────────────────────┘
```

### 2.2 현재 운영 중인 기능 (라이브)
- ✅ 사주 명식 자동 분석 (8자·십성·오행·격국·용신)
- ✅ 대운 80년 인생 흐름 그래프 (시각화)
- ✅ 12 카테고리 AI 자문 (직업·결혼·자녀·재정 등)
- ✅ 궁합(宮合) — 두 사주 비교 + 학파별 견해
- ✅ 택일(擇日) — 기간 내 좋은 날 추천
- ✅ 결정 도우미(決) — A/B 두 선택지 사주 비교 자문
- ✅ 한자 자동 병기 + 마우스 hover 의미 툴팁

### 2.3 데모
- 라이브: **https://ja-pyeong.vercel.app**
- 무료 체험: 회원가입 없이 사주 1회 분석 가능 (대표님 직접 확인 가능)

### 2.4 기술적 신뢰성
- 만세력 라이브러리 sxtwl 사용 (중국 천문대 데이터 기반)
- 60갑자·절기 계산 회귀 테스트 **316건 통과**
- 다중 LLM 교차검증 (Anthropic / OpenAI / Google) 인프라 보유
- 자평은 **사주 풀이의 정통성·근거를 코드로 증명**하는 거의 유일한 한국 서비스

## 3. 왜 TM 채널이 자평과 잘 맞나

### 3.1 단가 산수 — 다른 TM 상품과 비교

| 상품 | 계약가 | TM 수수료 (20-30%) | 가입 1건 마진 (CAC 100k 가정) |
|---|---|---|---|
| 알뜰폰 요금제 | 30~50k | 9~15k | **(-)** |
| 인터넷·IPTV 약정 | 200~400k | 60~120k | -40 ~ 20k |
| 보험 부가 특약 | 400~800k | 80~240k | -20 ~ 140k |
| 온라인 강의 1년 | 200~500k | 40~150k | -60 ~ 50k |
| **자평 표준 (39만 원)** | **390k** | **78~117k** | **-22 ~ 17k** |
| **자평 프리미엄 (89만 원)** | **890k** | **178~267k** | **78 ~ 167k** ⭐ |
| **자평 VIP (180만 원)** | **1,800k** | **360~540k** | **260 ~ 440k** ⭐ |

→ **프리미엄·VIP가 TM의 핵심 수익원**이 되며, 표준은 미끼·진입 티어.
→ 일반 통신·보험 채널보다 **건당 마진이 5~10배 두꺼움**.

### 3.2 콜이 잘 먹히는 이유
- **감정 트리거가 명확**: "요즘 결정하기 어려운 일 있으세요?" — 거의 모두 "예"
- **가격 정당화가 자연**: "동네 명리원 1회가 10~15만 원인데, 1년 무제한이 39만 원" (이건 합리적 비교)
- **자문위원 1:1이 클로징 카드**: 단순 앱이 아니라 "사람이 직접 봐 준다" — 한국에서 결정타
- **가족 패키지**가 자연스러운 업셀: 본인 → 배우자 → 자녀 → 부모

### 3.3 갱신·LTV
- 연 1회 결제 → 1년 후 자동 갱신 안내 콜
- 분기별 PDF 리포트가 갱신 명분 (받아 보면 다음 분기 기대됨)
- 자문위원과 라포 형성 시 갱신율 60% 이상 기대 (오프라인 명리원 단골 패턴)
- 가족 추가 신청 시 추가 수수료 발생

## 5. 파트너십 조건 — 협의 출발점

> 모두 협의 가능. 첫 미팅에서 조정.

### 5.1 수수료 구조
- 계약가의 **20~30%** (티어·볼륨에 따라 차등)
- 정산: **월 2회** (15일, 말일)
- 청약철회·환불 발생분은 **수수료 회수**

### 5.2 계약 형태
- **위탁판매**(자평 명의 결제, TM 수수료 정산) 추천
- 총판은 협의 가능 (단, 표시광고·약관 책임 강화 필요)

### 5.3 독점/비독점
- **지역·세그먼트 단위 독점** 협의 가능 (예: 수도권 50대 여성)
- 전국 단독 독점은 KPI 보장 조건부 가능

### 5.4 최저 가입 인센티브 (파일럿)
- 자평이 **첫 30일** 첫 100건 가입 시 **건당 추가 5% 보전**
- 미달분에 대해서도 협의 가능 (TM 입장 리스크 헷지)

## 9. 리스크 & 컴플라이언스 — TM이 안전한 이유

| 리스크 | 자평의 대응 |
|---|---|
| 표시광고법 (부당 표시·과대광고) | 자평이 **사전 검수한 멘트만** 사용. 콜센터 위반 시 자평이 1차 책임 |
| 전자상거래법 (청약철회) | 7일 100% 환불 보장. 결제·환불은 자평 시스템. TM은 1차 응대만 |
| 통신판매법 (녹취·약관 고지) | 자평 약관·고지 멘트 제공. 녹취만 TM이 보관 |
| 개인정보보호법 | 자평이 PIMS 수준 보안. TM은 결제 페이지 링크만 전송 |
| 자살·자해 위기 키워드 | 자평 가드레일이 즉시 109 안내로 단축. TM 멘트에도 동일 절차 명시 |
| 환불 분쟁 | **자평이 100% 처리**. TM은 회수 책임 없음 |
| "사주가 안 맞다" 클레임 | 자평 약관에 "참고용·결과 보장 불가" 명시. 자문위원 무료 추가 상담으로 1차 대응 |

→ TM 대표 입장에서 가장 큰 리스크인 **법적 책임·환불 회수·민원**은 자평이 떠안는 구조.

## 10. 로드맵 — 함께 만들 것

### Phase 1 · 파일럿 (1개월)
- 상담사 5명, 콜 일일 2,000건, 가입 100건 목표
- 자평: 무상 교육 + CPA 보전 5%
- 종료 시 데이터 리뷰 → KPI·수수료 재협의

### Phase 2 · 본 운영 (3개월차~)
- 상담사 15~20명 확대
- 자문위원 풀 확대 (자평이 영입)
- 갱신 콜 전담팀 분리

### Phase 3 · 확장 (6개월차~)
