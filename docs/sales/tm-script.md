## 0. 상담사 교육용 — 자평이란 무엇이고, 무엇이 아닌가

### 0.1 자평의 정체성 (3줄)
1. **결정론적 명리 엔진** + AI 보조 고전 해석 + 명리 자문위원의 **3층 구조**
2. 연해자평·삼명통회·적천수 등 **고전을 1차 근거**로 인용
3. 운세 예언이 아닌 **"결정 앞에 결을 짚는 자문"** — 슬로건: "결정 앞에, 자평."

### 0.2 자평이 아닌 것 (절대 말하지 말 것 — CI 훅이 자동 차단함)

| 금지 표현 | 이유 |
|---|---|
| "사주가 맞다·틀리다" | 자평은 결정 보조 자문이지 적중률 상품 아님 |
| "이걸 사면 운이 좋아진다" | 결과 보장 = 표시광고법 위반 |
| "100% 적중", "정확히", "반드시", "확실히" | 단정형 금지 |
| "병이 낫는다", "이 주식 사라" | 의료·법률·재무 단정 금지 |
| "오늘만", "지금만", "마감 임박" | 한정 마케팅 금지 (브랜드 무너짐) |
| **"놓치면 손해", "위기 시기 알림"** | 부작위 손해 단정 = 표시광고법 위반 |
| **"위기 시기를 알려드립니다"** | 공포 자극형 = 정신건강 윤리 이슈 |
| **"AI 사주"** | → **"AI 보조 고전 해석"** 으로 재정의 (절대 권위 오해 차단) |
| **"전문 역술가 인증"** (자격증 미공개 시) | 허위 표시 |
| **"자녀 사주로 진로 알아보기"** | 6개월 보류 — 절대 권유 금지 |

### 0.3 경쟁사 대비 자평의 차별 한 줄
> "타로·점성·동네 점집과 다릅니다. 자평은 명리학 고전(연해자평·삼명통회 등)을 그대로 인용하고, 학파별 견해 차이를 솔직하게 보여 드리며, 마지막에 자문위원이 검토합니다. **점이 아니라 자문입니다.**"

#### ① Premium (1:1) — 390,000원 / 년 (월 환산 32,500원)
- 앱 전체 기능 1년 무제한
- **분기 종합 PDF 리포트 4건**
- 대운 80년 인생 흐름 풀이
- **자문위원 1:1 전화 상담 연 2회 (회당 30분)**
- 주요 결정 학파 교차 검토
- 추가 자문 회차 5~15만 원/회 별구매 가능

#### ② Family / Couple — 590,000원 / 년 (월 환산 49,166원) ⭐
- Premium 전체 포함
- **가족 최대 4인 AI 분석**
- 가족 합·궁합 종합 진단
- **자문위원 1:1 통합 2회** (가족 대표가 받음. **시간 가족 수와 무관**)
- 택일 컨설팅 무제한 (결혼·이사·계약)
- 부부·부모자녀 패키지 모두 지원

## 2. 통화 스크립트

### 2.1 오프닝 (필수 — 30초 이내)

> "안녕하세요. **자평(子平) 명리 자문 안내** 드리는 [상담사명]입니다.
> 이 통화는 자평 서비스 소개와 신청 안내를 위한 **녹음 통화**임을 먼저 안내드립니다.
> 자평은 900년 명리학 고전을 기반으로 한 AI 보조 해석 + 자문위원 자문 서비스인데, 지금 **2~3분만** 시간 내주실 수 있으실까요?"

**거절 처리:**
- "지금 바빠요" → "예, 편하실 때 다시 안내드리겠습니다. 혹시 **저녁 7시 전후**가 괜찮으실까요?" (재콜 약속)
- "사주 안 봐요" → "예, 자평은 점이 아니라 **결정 자문**입니다. 잠깐만 한 가지만 여쭤도 될까요? 최근에 큰 결정을 앞두고 계신 게 있으신가요?" (스위치)
- "필요 없어요" → "예, 안내드릴 자료가 있으면 **카톡으로만 보내드려도** 될까요?" (리드 보관)

### 2.2 니즈 발굴 (3개 질문 이내)

> "고객님, 혹시 **요즘 결정하기 어려운 일**이 있으세요? 예를 들어 이직, 사업, 결혼, 자녀 진로 같은…"

> "전에 사주나 명리 보신 적 있으세요? 어떠셨어요?" *(있다고 하면)* "그때 받으신 풀이가 **근거가 명확**했나요, 아니면 그냥 결론만 들으셨나요?"

> "이번에 사주를 보신다면 어떤 게 가장 궁금하실까요?"

### 2.3 상품 소개 (니즈에 맞춰 1개 트랙)

#### 시나리오 A — "큰 결정 앞이다" → **Premium 추천**
> "그러시면 자평이 잘 맞으실 것 같습니다. 자평은 결정 앞에 사주의 결이 어느 쪽으로 기우는지 보여 드리는 자문입니다. 특히 Premium 패키지는 **자문위원이 직접 전화 드려서 1:1로 검토**해 드립니다.
> 가격은 **연 39만 원**, 월로 환산하면 **3만 2천 원** 수준입니다. 동네 명리원 1회가 10~15만 원인 걸 생각하시면, **1년 무제한 + 자문위원 1:1**이 들어가는 거예요."

#### 시나리오 B — "가족 다 같이 보고 싶다" → **Family 추천**
> "그러시면 **Family 패키지**가 맞으실 것 같습니다. 부부와 자녀까지 **가족 4인 사주**를 같이 관리하고, 가족 합도 분석합니다. 자문위원 1:1이 통합으로 **연 2회** 들어가요 — 가족 대표 한 분이 받으셔서 가족 종합 자문을 들으시는 형태입니다.
> 연 59만 원, 월 환산 5만 원이에요. 가족 한 사람씩 따로 명리원 가시면 1년에 그보다 더 쓰십니다."

#### 시나리오 C — "처음이라 부담돼" → **Premium 시작 추천 (Standard 언급은 자제)**
> "그러시면 **Premium 패키지**부터 시작하시는 걸 추천드립니다. 앱 모든 기능 + 분기 PDF 리포트 + 자문위원 1:1 2회까지 들어갑니다. 연 39만 원, 월 환산 3만 2천 원이에요.
> **7일 안에 마음에 안 드시면 100% 환불**되니까 일단 한 분기 써 보시는 분들이 많으세요."

### 2.4 클로징

> "그러면 [티어명] 패키지로 신청 도와드리겠습니다. 다음 세 가지만 확인해 주시겠어요?
> 1. 본인 명의 카드 결제 동의하시나요?
> 2. **결제 후 7일 이내 청약철회는 100% 환불**, 7일 이후엔 사용 일수 일할 환불 가능합니다. 동의하시나요?

| 한정 마케팅 ("오늘만", "지금만") | 자평 브랜드 정체성 무너짐 |
| 의료·법률·재무 단정 | 무자격 자문 + 법적 책임 |
| 약관·환불 고지 누락 | 결제 무효 |
| 녹취 동의 누락 | 통화 증거능력 상실 |
| 청소년·미성년자 가입 권유 | 자평 약관 위반 |
| 본인 아닌 사람 명의 결제 유도 | 명의도용 — 형사책임 |
| 자녀 사주 패키지 권유 | **출시 보류** 상품 — 절대 권유 금지 |
| 자살·자해 키워드 응답 시 상품 안내 | 즉시 상담 종료 + 1393 안내 |
| "AI 100% 정확" 류 표현 | 절대 권위 오해 |

### 위기 키워드 대응 (필수)
대화 중 "죽고 싶다", "자해", "끝내고 싶다" 등 키워드 감지 시:
```
"고객님, 지금 많이 힘드신 것 같습니다. 자평 상품 안내는 잠시 멈추고,
필요하시면 자살예방상담전화 1393번에 24시간 상담 가능합니다.
혼자가 아니십니다. 지금 잠깐 그쪽으로 연결되시는 게 어떨까요?"
```
→ 즉시 통화 종료, 사내 정신건강 가이드라인 매뉴얼 따라 사후 조치.

## 7. 가격 정당화 — 한 페이지 요약 (고객 발송용)

```
자평 패키지가 왜 이 가격일까요?

▶ 동네 명리원 1회 상담: 70,000~150,000원
▶ 자평 Premium (1년 + 자문위원 1:1 연 2회): 390,000원
   = 명리원 3~5회 비용 + 검증된 자문위원 동행

▶ 자평 Family (1년 + 자문위원 통합 2회 + 가족 4인): 590,000원
   = 가족 한 사람씩 1년에 12회 명리원 가시는 것보다 저렴

▶ 다른 사주 앱과 다른 점:
   1. 결정론 명리 엔진이 사주를 먼저 확정 (AI가 사주 세우는 게 아님)
   2. 모든 답변에 고전(연해자평·삼명통회 등) 출처 인용
   3. 학파별 견해 차이를 솔직하게 표시
   4. 자문위원이 사람이 검토 (Premium·Family)
   5. AI 단독 결론 X — "AI 보조 고전 해석" 구조

▶ 환불 보장:
   - 결제 후 7일 이내 100% 환불
   - 7일 이후 사용 일수 일할 환불
   - 자문위원 상담 이미 받은 회차만 제외

▶ 자평이 약속하지 않는 것:
   - 적중률·결과 보장 X
   - 의료·법률·재무 단정 X
   - 한정 마케팅·공포 자극 X
   = 자평은 "결정 보조 자문 도구"입니다.
```

## 8. 부록 — TM 채널 산수 (운영 참고)

- 콘택트 1건당 콜센터 비용: 약 4,000~7,000원
- 가입 1건당 CAC (가입률 5% 가정): 약 80,000~140,000원
- TM 대행 수수료 (계약가의 35% / 40%):
  - **Premium 39만 → 136,500원**
  - **Family 59만 → 236,000원**
- **손익분기**: 가입자 1명당 CAC 100k + 수수료 100k = 약 200k 회수 필요 →
  Premium 1건 손익분기 근접, Family 1건 약 14만 흑자

이 산수가 **Premium 39만 / Family 59만 + 수수료 35~40%가 되어야 하는 이유**.
