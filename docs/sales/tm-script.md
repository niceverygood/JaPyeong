# 자평(子平) 텔레마케팅 스크립트 + 가격 정당화 자료

> **상담사 교육용 + 실제 통화 사용용.** 자평의 정체성(고전 근거·학파 다양성·의사결정 자문)을
> 무너뜨리지 않는 선에서, 연간 패키지(390k / 890k / 1,800k)를 일시불로 클로징하는 게 목표.
>
> **녹취 의무.** 모든 통화는 통신판매법(전자상거래법)에 따라 처음에 녹취 고지, 결제 직전 7일
> 청약철회권 고지, 약관 동의 확인 3단계가 들어가야 한다. 빠지면 결제 자체가 무효가 될 수 있음.

## 0. 상담사 교육용 — 자평이란 무엇이고, 무엇이 아닌가

### 0.1 자평의 정체성 (3줄)
1. **결정론적 명리 엔진** + AI 자문 + 명리 자문위원의 **3층 구조**.
2. 연해자평·삼명통회·적천수 등 **고전을 1차 근거**로 인용.
3. 운세 예언이 아닌 "**결정 앞에 결을 짚는 자문**". 슬로건: **"결정 앞에, 자평."**

### 0.2 자평이 아닌 것 (절대 말하지 말 것)
- ❌ "사주가 맞다·틀리다" — 자평은 결정 보조 자문이지 적중률 보장 상품이 아님.
- ❌ "이걸 사면 운이 좋아진다" — 결과 보장 멘트는 표시광고법·전자상거래법 위반.
- ❌ "100% 맞다", "확실하다", "반드시" — 단정형 금지.
- ❌ "병이 낫는다", "주식이 오른다", "이혼 막아 준다" — 의료·재무·법률 단정 금지.
- ❌ "오늘만 이 가격" — 한정·불안 마케팅 금지 (브랜드 무너짐).

### 0.3 경쟁사 대비 자평의 차별 한 줄
> "타로·점성·동네 점집과 다릅니다. 자평은 **명리학 고전(연해자평·삼명통회 등)을 그대로 인용**하고, **학파별 견해 차이를 솔직하게 보여 드리며**, 마지막에 **사람 자문위원이 검토**합니다. 점이 아니라 **자문**입니다."

## 2. 통화 스크립트

### 2.1 오프닝 (필수 — 30초 이내)

> "안녕하세요. **자평(子平) 명리 자문 안내** 드리는 [상담사명]입니다.
> 이 통화는 자평 서비스 소개와 신청 안내를 위한 **녹음 통화**임을 먼저 안내드립니다.
> 자평은 900년 명리학 고전을 기반으로 한 AI + 자문위원 자문 서비스인데, 지금 **2~3분만** 시간 내주실 수 있으실까요?"

**거절 처리:**
- "지금 바빠요" → "예, 편하실 때 다시 안내드리겠습니다. 혹시 **저녁 7시 전후**가 괜찮으실까요?" (재콜 약속 시도)
- "사주 안 봐요" → "예, 자평은 점이 아니라 **결정 자문**입니다. 잠깐만 한 가지만 여쭤도 될까요? 최근에 큰 결정을 앞두고 계신 게 있으신가요?" (스위치)
- "필요 없어요" → "예, 안내드릴 자료가 있으면 **카톡으로만 보내드려도** 될까요?" (리드 보관)

### 2.2 니즈 발굴 (3개 질문 이내)

> "고객님, 혹시 **요즘 결정하기 어려운 일**이 있으세요? 예를 들어 이직, 사업, 결혼, 자녀 진로 같은…"

> "전에 사주나 명리 보신 적 있으세요? 어떠셨어요?" *(있다고 하면)* "그때 받으신 풀이가 **근거가 명확**했나요, 아니면 그냥 결론만 들으셨나요?"

> "이번에 사주를 보신다면 어떤 게 가장 궁금하실까요?"

### 2.3 상품 소개 (니즈에 맞춰 1개 트랙으로)

#### 시나리오 A — "큰 결정 앞이다"
> "그러시면 자평이 잘 맞으실 것 같습니다. 자평은 결정 앞에 사주의 결이 어느 쪽으로 기우는지 보여 드리는 자문입니다. 특히 프리미엄 패키지는 **자문위원이 직접 전화 드려서 1:1로 검토**해 드립니다.
> 가격은 **연간 89만 원**, 월로 환산하면 **7만 4천 원** 수준입니다. 동네 명리원 1회가 10~15만 원인 걸 생각하시면, **1년 무제한 + 자문위원 1:1**이 들어가는 거예요."

#### 시나리오 B — "가족 다 같이 보고 싶다"
> "그러시면 **VIP 패키지**가 맞으실 것 같습니다. 부부와 자녀까지 **가족 3인 사주**를 같이 관리하고, 가족 합도 분석합니다. 자문위원 1:1이 **분기마다 한 번씩** 들어갑니다.
> 연 180만 원, 월 환산 15만 원입니다. 가족 한 사람씩 따로 명리원 가시면 1년에 그보다 더 쓰십니다."

#### 시나리오 C — "처음이라 부담돼"
> "그러시면 **표준 패키지**부터 시작하시는 걸 추천드립니다. 자문위원 1:1은 없지만 앱의 모든 기능과 분기별 종합 리포트가 들어갑니다. 연 39만 원, 월 환산 3만 2천 원입니다.
> **7일 안에 마음에 안 드시면 100% 환불**되니까 일단 한 분기 써 보시는 분들이 많으세요."

### 2.4 클로징

> "그러면 [티어명] 패키지로 신청 도와드리겠습니다. 다음 세 가지만 확인해 주시겠어요?
> 1. 본인 명의 카드 결제 동의하시나요?
> 2. **결제 후 7일 이내 청약철회는 100% 환불**, 7일 이후엔 사용 일수 일할 환불 가능합니다. 동의하시나요?
> 3. **자평의 명리 자문은 의학·법률·재무 결정을 대체하지 않는 참고용**임을 안내드립니다. 동의하시나요?"

→ 모두 "예" 받으면 결제 단계로.

## 4. 결제·약관 안내 (필수 멘트, 빠지면 무효)

```
결제를 진행하기 전, 다음 사항을 안내드리고 동의를 확인하겠습니다.

1. 자평 연간 [티어명] 패키지, 결제 금액 [금액]원입니다.
2. 결제는 신용카드 즉시 결제이며, 본인 명의 카드로만 가능합니다.
3. 결제 후 7일 이내 청약철회 시 100% 환불됩니다.
   7일 이후엔 사용 일수를 제외한 잔여 일할 금액으로 환불됩니다.
   다만 자문위원 1:1 상담을 이미 받으신 경우, 해당 회차는 환불 대상에서 제외됩니다.
4. 자평의 명리 자문은 결정의 참고 자료이며, 의학·법률·재무 결정을 대체하지 않습니다.
5. 위 사항에 모두 동의하십니까?
```

## 5. 절대 금지 사항 (Compliance)

| 금지 행동 | 사유 |
|---|---|
| 적중률·결과 보장 멘트 ("100% 맞다", "운이 좋아진다") | 표시광고법 부당한 표시 |

| 의료·법률·재무 단정 ("이 병이 낫는다", "이 주식 사라") | 무자격 자문 + 법적 책임 |

| 청소년·미성년자 가입 권유 | 표시광고법 + 자평 약관 위반 |
| 본인 아닌 사람 명의 결제 유도 | 명의도용 — 형사책임 |
| 자살·자해 키워드 응답 시 상품 안내 | 즉시 상담 종료 + 109(자살예방) 안내 |
