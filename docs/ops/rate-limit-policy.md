# 자평 Rate Limit 다층 방어 정책

> **목적**: LLM 비용 폭주·봇 어그로·다계정 우회 차단
> **트리거 시나리오**: 디시 갤러리에 "무제한 사주 무료" 박제 → 봇 5천 대가 새벽 3시 동시 자문 API 폭주 → 일 4천만 원 발생
> **원칙**: 다층(회원·일·IP·디바이스·세션) 모두 동시 발동

---

## 1. Rate Limit 다층 구조

| 레이어 | 제한 | 트리거 동작 |
|---|---|---|
| **회원 일일 한도** | Basic: 20콜/일, Std: 100콜/일, Prem: 500콜/일, Free: 5콜/일 | 초과 시 paywall 모달 + 다음날 리셋 안내 |
| **IP 분당 한도** | 60 req/min (회원 무관) | HTTP 429, 1분 후 재시도 |
| **IP 일일 한도** | 1,000 req/day | HTTP 429 + 임시 차단 24시간 |
| **디바이스 fingerprint** | 동일 디바이스 다계정 = 1계정 한도 합산 | 추가 가입 차단 |
| **국가 단위** | 한국 외 트래픽 90% 차단 (관제 화이트리스트 제외) | HTTP 403 |
| **봇 시그니처** | User-Agent 분석 + Cloudflare Turnstile | 캡차 강제 |
| **세션 burst** | 10초 5콜 = 봇 의심 | 캡차 강제 |

## 2. Anthropic Budget Alert (LLM 비용)

| 임계 | 알림 채널 | 액션 |
|---|---|---|
| 일 50만원 | Slack #ops | 모니터링 강화 |
| 일 100만원 | Slack #ops + 대표 SMS | 무료 티어 일시 차단 검토 |
| 일 300만원 | 자동 셧다운 | 무료 티어 자동 중단, 유료만 유지 |
| 월 1500만원 | 대표 + CTO 긴급 회의 | BM 재계산 |

→ 운영 환경에서 `ANTHROPIC_BUDGET_DAILY_KRW=3000000` 환경변수로 자동 셧다운 설정.

## 4. 봇·다계정·우회 대응 매뉴얼

### 4.1 봇 의심 감지 신호
- 분당 10+ 콜
- 동일 IP에서 1시간 100+ 가입
- User-Agent 비표준
- 캡차 통과율 50% 이하
- 프롬프트 인젝션 시도 (특정 키워드)

### 4.2 자동 대응
1. **Tier 1 (의심)**: Cloudflare Turnstile 캡차 강제
2. **Tier 2 (확정)**: IP 24시간 임시 차단
3. **Tier 3 (반복)**: IP 영구 차단 + 디바이스 fingerprint 차단

### 4.3 운영자 매뉴얼 대응
- Slack 알림 즉시 확인
- Anthropic 콘솔에서 분당 콜 추이 확인
- 필요 시 **`/api/v1/chat` 엔드포인트 일시 회원 전용 전환** (무료 차단)
