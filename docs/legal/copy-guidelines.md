# 자평 카피 가이드라인 (Copy Guidelines)

> **목적**: 표시광고법·전자상거래법·자평 정체성 동시 준수
> **적용 범위**: 랜딩, 앱 UI, 푸시 알림, 이메일, TM 스크립트, 광고, PR
> **검증**: PR 단계 CI 훅에서 금지어 자동 차단

---

## 1. 절대 금지 어휘 (CI 자동 차단)

다음 단어가 카피·UI 텍스트에 포함되면 PR 자동 fail:

### 1.1 단정·예측 표현 (표시광고법 부당 표시)
- 예측, 적중, 맞춤, 100%, 정확히, 확실히, 반드시, 분명히
- "~할 것이다" 강한 미래 단정형

### 1.2 부작위 손해 단정 (표시광고법 + 윤리)
- 놓치면 손해, 안 보면 손해, 모르면 위험
- 위기 시기 알림, 운수 막힘, 운명 망함

### 1.3 한정·긴급 (브랜드 정체성)
- 오늘만, 지금만, 마감 임박, 단 X명

### 1.4 자격 미검증 (표시광고법)
- "전문 역술가 인증" (자격증 없으면)
- "국가공인" (명리는 국가공인 자격 없음)
- "AI 사주" → **"AI 보조 고전 해석"** 으로 재정의

### 1.5 결과 보장 (표시광고법)
- 보장, 책임 보장, 결과 보장, 운명 변경

### 1.6 비교 우위 (실증불가)
- "1위", "최고", "최강" (제3자 인증 없으면)
- "유일한", "오직 자평만"

→ 전체 목록은 `scripts/forbidden-words.txt` 참조.

## 2. 권장 어휘 대체

| ❌ 금지 | ✅ 권장 |
|---|---|
| 예측한다 | 해석한다 / 짚는다 |
| 적중률 99% | 명리 고전 해석 기반 |
| 반드시 ~한다 | ~할 가능성이 있다 |
| 놓치면 손해 | 지금 보면 다음 결정이 가벼워집니다 |
| 위기 시기 알림 | 주의 깊게 볼 구간 |
| AI 사주 | AI 보조 고전 해석 |
| 100% 정확 | 명리 고전에 근거한 해석 |
| 운명 변경 | 결정의 결을 짚는 자문 |
| 전문 역술가 검증 | 경력 N년 자문위원 |
| 1위 사주앱 | 결정 자문 카테고리 자평 |

## 3. 결과지 고정 디스클레이머 (필수)

모든 자문 결과 화면 **상단에 접을 수 없게** 노출:

> *"이 결과는 명리 고전 해석에 기반한 참고 자료이며 미래를 단정하지 않습니다. 의학·법률·재무 결정을 대체하지 않습니다."*

### 결과지 하단 — 모델 정보·해석 한계 박스

> 본 자문은 명리학 고전(연해자평·삼명통회·적천수 등)을 기반으로 자평 결정론 엔진과 AI 보조 해석이 결합한 결과입니다.
> 학파별 견해가 다른 항목은 함께 표시했습니다. 최종 결정은 본인이 합니다.
> 모델: claude-sonnet-4-5 · 엔진 v0.0.1 · 자문위원 검증: [Y/N]

## 4. 카피 사전심사 체크리스트 (PR 단계)

```
[ ] 금지어 사전 grep 통과 (CI 자동)
[ ] 절대표현 (100%, 반드시, 확실히) 0건
[ ] 부작위 손해 단정 (놓치면, 위기) 0건
[ ] 한정·긴급 (오늘만, 마감) 0건
[ ] 자격·검증 표기 (자격증 어휘) 0건 또는 실제 검증 자료 첨부
[ ] 디스클레이머 노출 (결과 화면 상단)
[ ] 모델/한계 박스 노출 (결과 화면 하단)
[ ] 후기·별점에 "이용자 개인 경험" 표기
[ ] A/B 학파 병기 (단일 정답 인상 회피)
[ ] 자녀·미성년 관련 입력 시 보호 게이트 동작
```

## 5. 톤 가이드 (자평 보이스)

### 5.1 정체성 3축
- **차분함** — 흥분·과장 X
- **정중함** — 친근하되 가볍지 않게
- **정직함** — 모르는 건 모른다, 학파가 갈리면 갈린다고 표기

### 5.2 좋은 카피 예시
- ✅ "당신의 사주 8글자 — 해석 도구로 읽어드립니다"
- ✅ "이 결정을 명리 관점에서 어떻게 읽을지 정리해드립니다"
- ✅ "이번 달 주의 깊게 볼 영역 3개"
- ✅ "두 사람의 사주 흐름을 함께 봅니다"
- ✅ "결정 앞에, 자평"

### 5.3 나쁜 카피 예시
- ❌ "AI가 99% 적중하는 사주!" (절대표현)
- ❌ "지금 안 보면 후회합니다" (부작위 손해)
- ❌ "오늘만 50% 할인" (한정·긴급)
- ❌ "당신의 위기 시기를 알려드립니다" (공포 자극)
- ❌ "운명 바꾸는 사주" (결과 보장)

## 6. 광고·PR 검수 절차

1. **카피 작성** → 본 가이드 자체 체크리스트 점검
2. **CI 자동 검수** — 금지어 grep, PR fail 시 수정
3. **법무 검토** — 외부 광고 매체 출고 전 변호사 1차 검토
4. **A/B 테스트** — 신규 카피는 5% 트래픽 먼저 노출, NPS·민원 모니터링
5. **출고 후 모니터링** — 매주 SNS/커뮤니티 자평 언급 트래킹

## 7. 위기 키워드 대응 (자살·자해·우울)

사용자 입력에 자살·자해·우울 키워드 감지 시:
1. 자문·풀이 결과 자동 중단
2. **자살예방상담전화 1393** 자동 노출
3. 정신건강의학과 권유 카드 노출
4. 결과 화면에 차분한 메시지: "지금 많이 힘드신 것 같습니다. 잠시 멈추고 전문가의 도움을 받아보세요."

→ 백엔드: `backend/src/ai/guardrails.py` `check_question()` 함수에서 이미 구현됨.

---

## 8. 자녀·미성년 관련 카피 (현재 보류)

자녀 사주 상품은 **6개월 출시 보류**.
재출시 시:
- 별도 카테고리로 분리
- "자녀에게 결과를 직접 전달하지 마세요" 강화 디스클레이머
- 자녀 결과지에서 단정 표현 자동 톤다운
- 14세 이상 자녀 본인 동의 링크 발송 의무화

## 9. 가이드라인 위반 시 처리

| 위반 강도 | 처리 |
|---|---|
| **경미** (단순 어휘) | PR fail → 수정 후 재PR |
| **중대** (절대표현·결과보장) | 즉시 출고 중단 + 법무 검토 |
| **법규 위반** (표시광고법·전자상거래법) | 외부 변호사 자문 + 광고 즉시 회수 |
| **반복 위반** | 카피 책임자 교육 + 워크플로우 재설계 |
